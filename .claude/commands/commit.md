---

현재 작업 트리의 변경분을 커밋하고 원격에 푸시한다.

## 절차

1. `git status`와 `git diff`(스테이징/언스테이징 모두), 최근 커밋 `git log --oneline -5`를 **병렬로** 확인해 변경 내용과 이 저장소의 커밋 메시지 스타일(한국어, 접두사 관례 등)을 파악한다.
2. 의미 있는 단위로 `git add` 한다. 별도 지시가 없으면 관련된 변경 전체를 스테이징한다.
   - `.gitignore` 대상이 실수로 포함되지 않았는지 확인한다. 민감정보(자격증명·키·IP)가 diff에 없는지 점검한다.
3. **한국어**로 간결한 커밋 메시지를 작성한다. 첫 줄은 요약, 필요하면 본문에 "무엇을·왜". 메시지 끝에 반드시 아래 라인을 붙인다:

   ```
   Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
   ```
4. 커밋 후 `git push` 한다. 현재 브랜치에 upstream이 없으면 `git push -u origin <branch>`로 설정한다.
5. 결과(커밋 해시·푸시된 브랜치)를 한 줄로 보고한다.

## 주의

- push는 되돌리기 어려운 작업이므로, diff에 의도치 않은 파일이나 민감정보가 보이면 푸시 전에 사용자에게 먼저 확인한다.
